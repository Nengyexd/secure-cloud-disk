我将按照您的要求修改登录页面背景，并为未来自定义壁纸做好准备。

### 修改计划

1.  **创建壁纸目录**：在 `src/assets/images` 下新建 `backgrounds` 文件夹，您可以将喜欢的壁纸放入其中。
2.  **修改登录页样式 (`Login.vue`)**：
    *   **背景调整**：将原本的深色渐变背景改为 **纯白** (`#ffffff`)。
    *   **预留接口**：在 CSS 中预留 `background-image` 代码注释，您只需取消注释并放入图片即可启用壁纸。
    *   **UI 升级**：同时应用我们新定义的 **Bilibili 粉色主题**，优化按钮、输入框和卡片的视觉效果，使其在纯白背景下依然精致美观。

### 效果预期
*   默认情况下，登录页将呈现干净、现代的纯白风格。
*   当您想换壁纸时，只需将图片命名为 `login-bg.jpg` 放入 `src/assets/images/backgrounds/` 目录，并取消一行 CSS 注释即可。
